# Estudio 105 Arquitectura

Demo de rediseño del sitio de Estudio 105 Arquitectura. HTML, CSS y JavaScript estáticos; no necesita instalación ni compilación.

## Publicación en Netlify

- Rama de producción: `main`.
- Directorio publicado: `dist`.
- Comando de compilación: ninguno.
- La configuración está en `netlify.toml`.
- `.netlify/` se excluye de Git porque contiene el estado local de Netlify.

El formulario prepara una consulta para revisarla y enviarla manualmente en WhatsApp. No almacena datos ni envía mensajes de forma automática.

Las imágenes del portafolio provienen del sitio original. Las imágenes conceptuales se identifican en la interfaz. Este sitio es una propuesta de diseño para presentar al negocio.
